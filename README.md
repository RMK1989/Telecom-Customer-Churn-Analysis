# Telecom Customer Churn Analysis using Power BI

## Project Overview
This project analyzes telecom customer data using Power BI to understand customer churn, identify customer retention patterns, and discover factors that influence customers to leave the service.

## Objective
- Analyze customer churn rate and retention trends.
- Identify customer segments with high churn.
- Analyze churn based on contract type, tenure, and payment method.
- Understand factors influencing customer attrition.
- Provide data-driven recommendations to improve customer retention.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Key Insights
- Analyzed customer churn patterns across different customer segments.
- Compared churn rates by contract type and customer tenure.
- Identified customer groups that may require retention-focused strategies.
- Developed interactive dashboards to support data-driven decision-making.

## Business Recommendations
- Improve retention strategies for high-risk customer segments.
- Encourage customers to choose long-term contracts.
- Monitor customer churn trends regularly.
- Use customer insights to improve satisfaction and loyalty.

## Conclusion
This project demonstrates practical skills in data cleaning, data analysis, DAX calculations, and interactive dashboard development using Power BI to support business decision-making.
